# dhilan's portfolio

Personal site for Dhilan Avula. The theme is a patient monitor: a heartbeat trace runs through the page, since most of what I build reads signals from people.

Built with Next.js, TypeScript, Tailwind CSS and Motion.

## Run it

```bash
npm install
npm run dev
```

## Editing content

All text lives in `content/profile.ts`. Photos go in `public/images/` and are referenced from the `photos` arrays there. The resume PDF goes in `public/Dhilan_Avula_Resume.pdf`.
